## 实测结论仅供参考

音源地址不稳定：同一首歌、同一个源，几分钟前能播、几分钟后就可能拿不回来（平台侧在变、聚合源内部链路也在变）。所以：

- 某首歌放不出来 → 面板里**换个源**再试，别改代码
- 换源后仍不行 → 隔一阵再试，或者在「在线音源」里点一下该源做「更新」（点第二次＝重新拉最新版）
- 几个源都不行 → 大概率是那首歌本身的问题（版权/下架/风控）

## 三种加源方式

1. **面板里点**：设置 →「音源」页 → 往下拉，文件列表里点一下即导入并启用
2. **在线音源**：面板内置 16 条官方/社区仓库直链，点 ⤓ 自动下载导入；点第二次＝更新到最新
3. **丢文件进来**：把 `.js` 复制到本目录，关掉面板再打开，列表里就多一条

下载会自动切换线路：直连 → `ghproxy.net` → `gh-proxy.com` → `ghfast.top`。
「从链接导入」时如果直连 GitHub 不通，手动在地址前拼镜像前缀：

```
https://ghproxy.net/https://raw.githubusercontent.com/作者/仓库/main/xxx/latest.js
```

## 怎么让某个源成为默认（新机器首次启动自动用它）

程序挑选顺序：文件名含 `default` → 目录里第一个（旧规则里的 `qdy` 已于 2026-10-17 失效移除）。
当前默认是 **`default-jiexiang.js`**（杰翔聚合，实测 20 首真播全过）。

想换默认源：把目标文件命名为 `default-xxx.js`，并给原来的默认源改名去掉 `default` 前缀即可（**别复制**，内容重复会被导入校验拒绝）。

## 批量更新本地副本

```bash
node _docs/tools/fetch-sources.js
```

会把指定仓库的源重新下载到本地（自动走镜像）。改脚本顶部的 `LIST` 数组来指定要哪些。

## 目录之间的关系

```
_sources/                              ← 开发期读取（项目根，不参与打包）
src/static/sources/*.txt               ← 随安装包分发的内置源（同一批，.txt 后缀躲开 webpack 压缩）
%APPDATA%\lx-music-desktop\sources\    ← 打包运行时真正生效的目录（asar 内只读，首次启动自动铺一份）
```
