# 音源目录

程序的「设置 → 音源」面板会**自动列出这个目录里的所有 `.js` / `.txt` 文件**，点一下就导入并启用。
往这里丢一个新文件、重开面板，它就会出现在列表里 —— **不用改代码，也不用重新编译**。

所有文件都来自社区仓库 [pdone/lx-music-source](https://github.com/pdone/lx-music-source)（持续更新）。
想拿最新的：面板「音源」页最下面的**在线音源**，点一下直接从网上拉。

## 实测可用性（2026-09-16）

用《稻香》试播的结果：

| 能播 | 播不了 |
|---|---|
| `qdy` `sixyin` `lx` `flower` `grass` `juhe` | `changqing` `huanyin` `huibq` `ikun` |

**但这张表只是当时的快照，别当铁律。** 音源地址本来就不稳定 —— 同一首歌，同一个源，几分钟前能播、几分钟后就可能拿不回来（平台侧在变、聚合源内部链路也在变）。所以：

- 遇到某首歌放不出来 → 面板里**换个源**再试，别改代码
- 换源后还是不行 → 隔一阵再试，或者点一下该源做「更新」（在线音源里再点一次 = 重新下载最新版）
- 几个源都不行 → 大概率是那首歌本身的问题（版权/下架/风控），不是配置问题

## 怎么加新源

三个办法，任选：

1. **面板里在线拉**（推荐）：设置 → 音源 → 最下面的「在线音源」，选一个点 ⤓
2. **从网上抄一条链接**：面板里「从链接导入」，粘贴一个 `latest.js` 的地址
   （GitHub 直连不通时，在地址前拼 `https://ghproxy.net/` 走镜像）
3. **手动放文件**：把 `.js` 拷进这个目录，重开面板

## 怎么让某个源变成默认（新机器首次启动自动用它）

程序挑选顺序是：文件名含 `default` → 含 `qdy` → 目录里第一个。

所以想换默认源，把目标文件改名成 `default.js` 即可。

## 批量更新本地副本

```bash
node _docs/tools/fetch-sources.js
```

会把仓库里的源全部重新下载到这个目录（自动走镜像），覆盖旧文件。
